# Paper 004: Lightmatter Passage M1000 — 3D Photonic Superchip for AI Interconnect

**Tags:** optical-interconnect, photonic-compute, co-packaged-optics  
**Date:** March 2025  
**Source:** Lightmatter / HPCwire / DataCenterDynamics  
**URLs:** https://lightmatter.co/press-release/lightmatter-unveils-passage-m1000-photonic-superchip-worlds-fastest-ai-interconnect/

## Summary

Lightmatter unveiled the Passage M1000, a 3D photonic "superchip" designed as a photonic interposer to interconnect large AI accelerator arrays and switching fabrics. At SC25, Lightmatter demonstrated four production racks using M1000 hardware.

## Key Technical Specifications

- **Total optical bandwidth:** 114 Tbps (record-breaking at announcement)
- **Architecture:** 3D stacked photonic interposer
- **DWDM:** 16-wavelength bidirectional per fiber
- **Record (March 2026):** 1.6 Tbps per fiber via Passage CPO chiplet
- **Bandwidth density vs NPO:** 8× improvement
- **Product roadmap:** M1000 → L200 (2026 CPO) → L20 (6.4 Tbps, late 2026 sampling)

## Architecture Notes

The Passage platform uses a photonic interposer as a 3D layer beneath compute and networking dies. Light propagates within the interposer plane to provide ultra-dense chip-to-chip connections. The M1000 integrates with latest XPU and switch silicon. The L20 module supports both near-packaged optics (NPO) and near-board optics (OBO) configurations.

## SC25 Demonstration (November 2025)

Lightmatter demonstrated first 16-wavelength bidirectional link achieving 8× bandwidth density vs existing solutions. Four production racks shown including M1000 and Passage 50 hardware.

## Record Achievement (March 2026)

Passage CPO chiplet achieved 1.6 Tbps per single fiber using 16-wavelength DWDM architecture. This represents a milestone in per-fiber bandwidth density.
